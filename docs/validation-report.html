How to read this report

“How LensForge did” comes from running the tests for this report. A small pytest plugin recorded every numeric comparison each test made (pytest.approx, numpy assert_allclose, and plain error < bound asserts), and the table shows the one that came closest to its tolerance. Parametrised tests are pooled over all their cases. “Share of tolerance used” is that worst error divided by the allowed error: a short bar means LensForge agrees with the truth by much more than the test demands. A few tests check a flag or a sign rather than a number, and are marked as exact. To regenerate this page, run python tools/validation_report/run.py.

Convention differences found and how the tests handle them

  • Seidel sign. Optiland’s Seidel sums are the negative of LensForge’s. LensForge follows Welford and Zemax (S1 > 0 for an under-corrected positive lens), and the thin-lens test confirms Welford’s signs. The Optiland tests compare against −Optiland. The docstring in lensforge/analysis/seidel.py writes the Lagrange invariant H with the opposite sign to Welford; that changes no result because H only appears squared.
  • TAST. LensForge used to report TAST = S3/(n′u′), the full separation of the tangential and sagittal foci. Since PR #76 it follows Zemax and Optiland, S3/(2n′u′), and LAST halved with it. TSFC and TTFC did not change, and the test checks TTFC − TSFC = 2 TAST.
  • OPD reference sphere for non-primary wavelengths. LensForge centres every wavelength’s reference sphere on the primary-wavelength chief ray; Optiland uses each wavelength’s own chief ray. Off axis the fans differ by a tilt of up to 0.03 waves on this lens, so the test removes a linear term before comparing and requires the residual to be under 1e-3 waves.
  • GEO spot sampling. Both codes trace 6 hexapolar rings, but Optiland starts each ring at a different angle, so the largest sampled ray (GEO radius) differs by up to 0.45 % at full field. The RMS radius does not depend on the starting angle and agrees to about 1e-7.
  • MTF frequency scale off axis. LensForge fits the image-space NA to all pupil rays; Optiland uses marginal-ray direction differences projected on the image plane. This is the largest remaining FFT MTF difference (up to 0.008 off axis, 0.001 on axis).
  • Strehl definition. LensForge’s Strehl is peak / perfect peak, as in OpticStudio, so at 1 wave of defocus it reports the brightest ring rather than the dark centre.

Not yet covered by a truth comparison

  • Published Seidel tables from a textbook or from Zemax output. Seidel sums are checked only against closed form and Optiland.
  • Off-axis OPD against a closed form, and fifth-order aberration coefficients.
  • Spot diagrams and fans through aspheres, gratings or decentred systems against another code.
  • Polychromatic MTF against another code (Optiland’s MTF is monochromatic only).
  • Tolerancing and global optimisation results. Those tests check behaviour (bounds, reproducibility, compensators), not agreement with an external truth, and are left out of this report, as are file-format, UI and layout tests.

Left out on purpose: tests that only compare LensForge with itself (for example JSON round trips, multi-configuration copies, or the default merit function against the analysis it mirrors). The non-sequential vs sequential comparison is kept because the two tracers are separate code.
